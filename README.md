# Sistema de Gestión para Laboratorio Clínico

Sistema web desarrollado para optimizar la recepción de órdenes, la gestión de catálogos analíticos y la emisión de reportes de resultados en la unidad de un de laboratorio hospitalario.

El objetivo principal del proyecto fue digitalizar los procesos manuales en papel, mejorando el tiempo de respuesta y manteniendo un historial organizado de las muestras y pacientes.

## Tecnologías utilizadas

- Frontend: React, Tailwind CSS
- Backend: PHP (API REST)
- Base de Datos: MySQL
- Diseño UI: Figma
- Control de versiones: Git y GitHub

## Funcionalidades principales

- Gestión de pacientes: Registro, búsqueda e historial clínico digital.
- Control de exámenes: Configuración de perfiles analíticos y rangos de referencia.
- Carga de resultados: Validación de valores de laboratorio para reducir errores de digitación.
- Reportes: Generación automática de informes en formato PDF.
- Módulo administrativo: Control de acceso por usuarios y roles.
